# Charged quirkonium helicity pilot

This repository holds an adversarial literature/physics feasibility audit of helicity and leptonic angular observables for charged quirkonium decays into W gamma and W Z. The initial material is a pilot, **not** a complete gauge-invariant helicity-amplitude calculation or a publication claim.

Work is developed on an isolated `research/pilot1-literature-model-gate` branch. No detector simulation, formation fractions or ATLAS discovery/exclusion claims.
